# Event catalogue codebook

The central experiment’s authoritative event input is `data/structural_surface/input/events.csv`; its hash is in the bundle manifest.

| field | meaning |
|---|---|
| `id` | stable event identifier |
| `date` | event date and forecast origin (`YYYY-MM-DD`) |
| `event_class` | curated surface category, used only by the surface arm |
| `title` | human-readable description |

Rows are curated geopolitical or oil-policy events, not a probability sample. Event class is an encoding, not an outcome or a claim of structural equivalence. In the central experiment it never controls eligibility: every prior, outcome-closed case satisfying the registered data rules enters both arms. Class affects only surface distance.

Legacy hand-coded escalation outcomes, anticipated flags, severity scores, and prose dossiers are outside the central estimand unless the registration names them.
